# D&D 5E All-in-One App

## Introduction

This is a personal passion project created by me in 2012 for my D&D sessions to help automate and track some of the more tedious aspects of combat to keep the game running at a faster pace. Over the years, I have added an enormous number of features beyond just combat functionality, and I continue to use it on a weekly basis to this day. The app has been built and optimized around my own personal use, prioritizing very fast inputting and executing of commands. As such, this app does not have a UI, and instead operates like a console, executing commands the user inputs via keyboard.
